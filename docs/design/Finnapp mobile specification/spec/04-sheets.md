# 04 · Sheets and confirmations

Every sheet uses the one primitive from `spec/02-components.md`. A sheet is described by:
kicker, title, optional fields, optional toggle, optional hint, optional inline actions,
optional list(s), and its two footer buttons. `—` means the button is absent.

## Choose sheet (replaces every native picker)

Kicker `CHOOSE`, title = the field name, no footer buttons. Body is a list of options;
the current one shows an accent `✓` on the right. Tapping an option applies it and
returns to wherever the picker was opened from (the form, or the sheet underneath).

Option sets: Account, Category, Destination, Type, Kind, Storage, Purpose, Asset, Role,
Repeats, Source, Period, Pair, Plan item, Transaction, From account, and any date field
(Start date, End date, First due, From, To, Financial date, Date).

## Confirmations

| Key | Title | Body | Buttons |
|---|---|---|---|
| Close period | Close this period? | The current balance is saved in period history and the period becomes read-only. You can start a new period right away. | Cancel · **Close period** (accent) |
| Delete transaction | Delete this expense? | It stays in history as Deleted but no longer affects balances or periods. | Cancel · **Delete** (destructive) |
| Archive account | Archive this account? | It disappears from the list and stops counting toward Total capital. History is kept and it can be restored later. | Cancel · **Archive** (destructive) |
| Delete category | Delete Groceries? | 12 transactions keep their history and move to Uncategorized. Nothing is removed from balances. | Cancel · **Delete** (destructive) |
| Delete rule | Delete this rule? | Upcoming items generated by it disappear from Plan. Already linked transactions stay untouched. | Cancel · **Delete** (destructive) |
| Log out | Log out of john? | You will be signed out on this device. Your data stays safely in your workspace. | Cancel · **Log out** (destructive) |
| Saved | Saved | *(varies by operation — see `spec/06-content.md`)* | **Done** (accent, no Cancel) |

Rule: the body always states the **consequence**, never repeats the question.
